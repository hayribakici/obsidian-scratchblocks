# Obsidian-Scratchblocks

This is a fork from [shabegom/obsidian-scratchblocks](https://github.com/shabegom/obsidian-scratchblocks/), which renders scratchblocks codeblocks into the [Obsidian](https://obsidian.md) editor.

## Usage

This plugin does two things:

1. it exposes the `scratchblocks` [library](https://scratchblocks.github.io/) at the top level of Obsidian so you can use it inside templater or other code running plugins.

2. It renders `scratchblock` code blocks in scratch format

**Example:**

~~~suggestion
```scratchblock
when green flag clicked
```
~~~

## Contributing

To make changes to this plugin, first ensure you have the dependencies
installed.

```
npm install
```

### Development

To start building the plugin with what mode enabled run the following command:

```
npm run dev
```

_Note: If you haven't already installed the hot-reload-plugin you'll be prompted
to. You need to enable that plugin in your obsidian vault before hot-reloading
will start. You might need to refresh your plugin list for it to show up._

### Releasing

To start a release build run the following command:

```
npm run build
```
